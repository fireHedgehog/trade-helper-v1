## Decision

Prioritise **cross-sectional equity momentum (CS-01)** for a preregistered protocol.
This is the same candidate parked at [cycle 1](2026-08-19-cycle-1.md) ("Candidate C")
and again at [cycle 6](2026-08-20-cycle-6.md) — both times disqualified at `Data
readiness = 0` because the ~500-symbol universe had no point-in-time membership,
only today's survivor list. That is no longer true: [`universe_pit.py`](../../backend/app/universe_pit.py)
(`0.81.0`) ingests a free, point-in-time S&P 500 membership history, live-verified.
This record re-scores the same candidate against that one changed fact — nothing
else about the claim changed, and the operationalization record
([cross-sectional-momentum-v1.md](../research-hypotheses/cross-sectional-momentum-v1.md))
states the scope narrowing this implies (S&P 500 only, not the full prior ~500-symbol
universe; 2001 onward, not the full history) plus the one new gap this exposes
(§ Data feasibility: `bars` itself may still lack price history for a name delisted
before `fetch.py` ever ran — a residual exclusion list, not a silent gap).

## Candidate — cross-sectional equity momentum, re-scored

| Field | Pre-result definition |
|---|---|
| Claim | Among S&P 500 members at each rebalance date (point-in-time, not today's list), prior 6-month return rank predicts subsequent 1-month return rank. |
| Scope | S&P 500 only (`universe_pit.py` does not cover Nasdaq-100 or the XL sector ETFs — a real narrowing from the original ~500-symbol ambition, disclosed, not hidden), 2001-01-01 onward. |
| Mechanism | Behavioural underreaction / gradual information diffusion (Jegadeesh & Titman 1993) — plausible, not assumed. |
| Market-belief proxy | Trailing 126-session return, computed from real point-in-time membership at each rebalance date. |
| Reality proxy | Subsequent 21-session return, same point-in-time eligible set. |
| Information set | `members_asof(t)` plus each eligible member's trailing close history through `t` — nothing later. |
| Estimand | Pooled Spearman rank correlation between formation rank and forward rank, same statistic as ETF-12 rotation and the feasibility check. |
| Alternatives | Size/liquidity confound within the index; sector-rotation disguised as momentum (no sector labels in this codebase, a named gap); residual survivorship from `bars`' own coverage start, distinct from membership survivorship. |
| Falsifier | Observed correlation at or below the block-permuted null's preregistered one-sided threshold. |
| Data feasibility | **Now `2`** (was `0` at cycle 1/6): point-in-time membership exists, free, live-verified. Residual gap named, not hidden: a name delisted from the S&P 500 before `fetch.py` ever captured its price history is unrecoverable from this codebase's existing data and must be its own disclosed exclusion list, same discipline the feasibility protocol's §3 used. |
| Expressions | Long-short quintile (primary, matches the claim's own shape); long-only top-quintile overlay against Passive ETF-12 v1 (secondary, a different portfolio claim); `no trade` if the floor isn't cleared. |
| Path and risk | Monthly quintile-reconstitution turnover and cost (must be charged, per `factor_zoo`'s own `round_trip_cost_bps` precedent); concentration in a handful of sectors/megacaps; no small-cap tail (S&P 500 only, so liquidity risk is low relative to the original ~500-symbol ambition). |

## Benchmark suitability

Primary comparator is the same statistic ETF-12 rotation and the feasibility check
used (pooled rank correlation vs. its own block-permuted null) — not a funded
portfolio benchmark at this stage. If the correlation clears its floor and a
long-only expression is later proposed, Passive ETF-12 v1 and SPY remain the
relevant funded diagnostics, per [ADR 0005](../adr/0005-product-objective-and-portfolio-benchmark.md).
