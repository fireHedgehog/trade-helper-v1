## Decision

Prioritise **Candidate A — Turn-of-month calendar effect**. It scores
`15/16`, the highest of any candidate this session tied with RSI, is the
first mechanism family this session that is time-based rather than
price-based, needs no new data and no new infrastructure, and directly tests
"calendar coincidence" — an alternative explanation named but never checked
in two prior candidate docs (SMA Cross v1, ETF-12 rotation). Candidates B
(day-of-week) and C (overnight-gap) are both eligible but not selected this
cycle: B shares real mechanism overlap with A and would not be independent
evidence if bundled together; C is not implementable today without a new
joint-resampling design step of its own.

## Candidate A — Turn-of-month calendar effect

| Field | Pre-result definition |
|---|---|
| Claim | Mean daily log return on turn-of-month days (the last trading day of the month plus the first `3` trading days of the following month, per Lakonishok and Smidt 1988) is materially higher than mean daily log return on all other days, distinguishable from a block-resampled null with the same serial-dependence structure. |
| Scope | The 12 locked ETFs, adjusted daily close, full available history. Unlike every prior candidate this session (event at $t$ predicts a forward $K$-session return), this is a contemporaneous realized-return partition — no forward horizon, no forecast lag — the standard construction in the turn-of-month literature. |
| Mechanism | Standardized institutional cash-flow timing (Ogden 1990): payroll, dividend, pension, and portfolio-rebalancing flows cluster at month-end/month-beginning, creating a temporary liquidity/demand effect around those specific days. This is an institutional-flow-timing story, not a technical-pattern or trend/momentum mechanism — genuinely orthogonal to everything tested this session. |
| Market-belief proxy | None in the technical-analysis sense — the proxy is the calendar itself, known in advance without observing any price. This is the first candidate this session with zero look-ahead risk by construction. |
| Reality proxy | Realized daily log return on the classified day. |
| Information set | The trading-day calendar only; no price information is used to define the event. |
| Estimand | (Mean daily log return on turn-of-month days) minus (mean daily log return on all other days), tested one-sided (favourable is positive) against a block-resampled null. |
| Alternatives | (1) The effect is a volatility-timing artifact, not a return-level effect — disclosed via a non-gating volatility-comparison diagnostic between the two groups, the same lesson SMA Cross v1's confound already taught this session. (2) The literature's historically-documented effect has decayed in the modern, highly liquid, heavily arbitraged ETF era (this project's sample sits almost entirely in the post-2002 period); a null result here would be the historically expected honest outcome, not a surprise, and is stated as such up front rather than discovered after the fact. (3) An equity-specific artifact rather than a genuine market-wide calendar effect — addressed by the same 3-of-6-cluster breadth gate used for prior candidates, since the 12-ETF universe spans equities, bonds, gold, and commodities. |
| Falsifier | Observed differential is not distinguishable from the block-resampled null, or breadth/concentration gates fail, or the effect appears equity-only (failing the cluster-breadth gate) rather than market-wide. |
| Data feasibility | Fully available today — only the existing `date` column already present for every row; no new fetch, no new column. |
| Expression candidates | No-trade event study (required first bounded experiment). Not a tradeable expression by itself: a 4-day/month window is far below any viable trading frequency once round-trip costs are considered; any later expression would need its own separately locked cost/execution protocol. |
| Path and risk | Trivially high event count (turn-of-month days are ~19% of trading days) removes the power-limitation risk that closed RSI and nearly closed Wave Pull — the live risk here is the opposite: whether ~20 years of daily data in 12 correlated instruments gives genuinely independent information, or whether Holm correction across 12 highly-correlated assets is doing most of the work of a much smaller effective sample. |

## Candidate B — Day-of-week calendar effect

| Field | Pre-result definition |
|---|---|
| Claim | Mean daily log return differs by day-of-week (the classic "Monday effect," French 1980), distinguishable from a block-resampled null. |
| Scope | Same 12-ETF universe and data as Candidate A; day-of-week label instead of turn-of-month label. |
| Mechanism | Same broad calendar-effects family as Candidate A, but with weaker, more contested grounding — day-of-week effects are widely reported in later literature as decayed or reversed after 1987 and after decimalization, unlike turn-of-month's more consistently documented persistence through the 2000s. |
| Alternatives | Same three alternatives as Candidate A, plus a fourth specific to this candidate: real overlap with Candidate A (both are calendar-position effects; if both were found material, they would not be independent evidence of two distinct mechanisms without a shared-cause check). |
| Falsifier | Same structure as Candidate A. |
| Data feasibility | Identical to Candidate A — zero new data or infrastructure. |
| Path and risk | Same power profile as Candidate A (day-of-week days are ~20% of trading days, no power concern) but the literature itself suggests the most likely honest outcome is a decayed/reversed pattern rather than a clean null or clean effect — a messier read to report than Candidate A's cleaner "not yet tested" framing. |

## Candidate C — Overnight-gap conditioned forward return

| Field | Pre-result definition |
|---|---|
| Claim | A large overnight gap (open at $t$ vs. close at $t-1$) predicts a forward $K$-session return, distinguishable from a generic-volatility placebo and a block-resampled null. |
| Scope | The 12 locked ETFs, adjusted daily open and close, full available history — the first candidate this session to use the open price at all. |
| Mechanism | Overnight-return concentration / day-session price-discovery literature (e.g. Berkman et al. 2012) — a market-microstructure and order-flow story, genuinely distinct from both the trend/momentum family and the calendar-effects family. |
| Alternatives | (1) Gap size correlates with realized volatility — the same generic-volatility confound that closed SMA Cross v1 — so the placebo must explicitly separate gap direction/magnitude from plain volatility, a lesson already learned once this session, not a new risk to discover the hard way. (2) As a literal daily round-trip, any real effect is almost certainly swamped by this project's own ~0.3-0.4% round-trip cost defaults; must be framed as a low-frequency conditioning signal from the start. |
| Falsifier | Observed effect is not distinguishable from the block-resampled null, or is fully explained by the volatility placebo. |
| Data feasibility | Open and close are both already in the bars table for every symbol; no new fetch. |
| Path and risk | **Not implementable today.** The existing event-recomputing bootstrap scaffold reconstructs a single synthetic *close-price* path per resample; a gap event needs two *paired* series (overnight and intraday return) resampled *jointly* to preserve their real relationship on a synthetic path — nothing in this codebase does that yet. The nearest precedent is cross-sectional rotation's joint-panel resampling (same resampled dates applied across assets), but that is a different kind of joint design (across assets, not across two return components of one asset) and would need its own adaptation, not direct reuse. |

Notes on scoring, stated plainly:

- **A's rationale (2) vs. B's (1):** both are real, published literature, but
  turn-of-month's cash-flow-timing mechanism (Ogden 1990) is more
  specifically causal than the day-of-week effect, which is widely
  characterized in later literature as decayed/reversed rather than a live,
  mechanistically-grounded pattern.
- **A and B's product relevance (1):** same structural cap as every
  no-trade-stage candidate this session — a 4-day/month or 1-day/week event
  is far below viable trading frequency once costs are considered, so this
  can only ever inform a conditioning signal, not a standalone strategy.
- **A's distinct information and diversification (2, 2) vs. B's (1, 1):**
  A and B sit in the same calendar-effects family, so *relative to each
  other* neither is fully orthogonal; A is scored higher because it is
  additionally distinct from the trend/momentum family that dominates this
  session's five closed results, while B carries both A's family-overlap
  and no additional new-family diversification of its own once A exists.
- **C's implementability (0):** the only zero on this scorecard. C's
  rationale, distinct-information, and diversification scores are as strong
  as A's — the joint-resampling machinery, not the idea, is what's missing.
  This is scored honestly low rather than rounded up, per the adversarial
  verification that corrected an earlier, more optimistic cost estimate for
  this exact candidate.
