## Decision

Fed put is the only scoreable, eligible candidate this cycle — not disqualified like cross-sectional, not yet-formalized like the other 6 macro variables. **Not preregistered yet**: Data readiness and Implementability are `1`, not `2`. Next engineering steps, in cost order, before preregistration:

1. Ingest `TREAST`/`TREAS10Y` via `macro_pit` (cheap, engine exists).
2. New ingestion module for `fiscaldata.treasury.gov`'s buyback dataset (free, keyless REST API, not yet built).
3. Design the Thesis Track small-*n* statistical method (the real work — no existing precedent in this codebase).

The 6-variable macro library remains parked at idea-stage; promoting any one needs its own operationalization record first, same gate Fed put already passed.
