## Candidate A — Wave Pull impulse-pullback continuation

| Field | Pre-result definition |
|---|---|
| Claim | After a strong short-horizon impulse (close up `≥6%` over the trailing `8` sessions), a completed close breaking above the subsequent `3`-session pullback's own recent high predicts a positive forward `10`-session return, distinguishable from a generic short-horizon breakout with no prior impulse requirement. |
| Scope | The 12 locked ETFs, adjusted daily OHLCV, full available history. Deliberately close-price-only — the existing `WavePull` prototype uses intraday high/low for its pullback range; this protocol substitutes a close-only rolling extreme, the same scope decision already made for TA Breakout v1, to stay compatible with the proven event-recomputing bootstrap. |
| Mechanism | Short-horizon underreaction/continuation: a genuine strong price move reflects real information flow; a brief pause (pullback) lets the market digest it, and resumption (breakout of the pullback) signals continuation rather than exhaustion. Distinct in timeframe and precondition from CTA v1's `~100`-session trend filter and TA Breakout's multi-touch resistance — but shares the general "breakout as trigger" family, a real overlap to track, not ignore. |
| Market-belief proxy | The impulse itself — the market's already-priced assessment of the recent strong move. |
| Reality proxy | Forward `10`-session return following the pullback breakout. |
| Information set | Adjusted daily close through the completed event close only; no future bar. |
| Estimand | Mean forward `10`-session log return conditional on the event, tested against a block-resampled, event-recomputed null — identical method to RSI oversold reversal and TA Breakout v1. |
| Alternatives | (1) The effect is just a generic short-horizon breakout, with the impulse precondition adding nothing — controlled via a placebo requiring only the breakout, not the impulse (the same "strip the distinguishing mechanic" design used for TA Breakout's placebo). (2) Volatility-regime effect — impulses co-occur with elevated volatility. (3) Overlap with TA Breakout's own breakout family — flagged, not assumed away; both being `material_and_consistent` would need a shared-mechanism check before treating them as independent evidence. |
| Falsifier | Observed mean forward return is not distinguishable from the block-resampled null, or the plain-breakout placebo (no impulse precondition) achieves an equal or larger forward return, showing the impulse precondition adds nothing beyond a generic breakout. |
| Data feasibility | Fully available today — identical 12-ETF adjusted daily OHLCV already used by every candidate this cycle; no new data source. |
| Expression candidates | No-trade event study (required first bounded experiment). If it clears its gate: a long-only entry-on-event, stop/target-on-exit rule matching the existing prototype's own risk mechanics, benchmarked separately under its own locked cost/execution protocol. |
| Path and risk | Compound precondition (impulse AND pullback-breakout) is likely rarer than either RSI's or TA Breakout's triggers — real risk of an insufficient-event-count result on some assets, disclosed honestly if it occurs rather than papered over. Gap risk and whipsaw risk apply to any later tradeable expression, not this no-trade study. |
