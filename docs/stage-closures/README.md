# Stage closures

Status: durable paradigm-boundary record. Written only when a research
line, mechanism family, or infrastructure stage is being deliberately
closed or parked and the active research question is genuinely changing —
not written for every version bump, the same bar `roadmap.md` already
applies to a Stage transition. This is a sub-Stage mechanism, not a
replacement for Stage 8/9/10/11 numbering: a record here can close one
research *line* inside an still-open Stage (for example, inside Stage 9A)
without the Stage itself moving.

Purpose: prevent silent research-style drift. A fresh reader — you, three
months later, or a memory-free agent — must be able to reconstruct from one
file why a research line stopped, what it proved and did not prove, what
must never be re-litigated, and what substantive gate condition justified
moving on, without reading the full changelog or roadmap narrative and
without re-deriving the reasoning from feel. This is a constitutional
mechanism, not an operational one: it exists specifically to distinguish a
deliberate, reasoned pause from an emotion-driven or token-cost-driven one.

Template: `YYYY-MM-DD-topic.md`, containing exactly six sections, in order:

1. **The question this line asked** — its estimand, stated precisely enough
   that "does the next line ask something different" is a checkable fact,
   not a feeling.
2. **Complete evidence inventory** — every closed result this line
   produced, one line each, linked. A list, not prose, so nothing is lost
   to summarization.
3. **Lessons that must not be re-litigated** — the accumulated
   local-optimum guard for this line, extracted once so it does not need
   re-deriving from nine separate result docs.
4. **Closed vs. merely parked, and why** — say explicitly which one this
   is. A park keeps the door open under a stated condition; a close does
   not. Never leave this ambiguous.
5. **The explicit gate condition that justified moving on** — must be
   substantive (an evidentiary or structural reason, e.g. mechanism-space
   exhaustion) never fatigue, token cost, or boredom alone. If the honest
   reason is cost or interest, say so plainly rather than dressing it as
   evidence.
6. **The next line's opening statement** — what question comes next, how
   its estimand differs, what it inherits. If the next line is not yet
   chosen, say that explicitly and name the live candidates without
   crowning one — a closure record must never smuggle in a decision that
   hasn't actually been scored.
