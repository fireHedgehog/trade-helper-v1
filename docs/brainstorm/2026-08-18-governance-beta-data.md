# 2026-08-18 — governance, β framework, data policy

> Brainstorm · non-evidential · loaded only on explicit request · no acceptance weight. Distilled from an author–agent heuristic session; not a contract.

## Distilled insights

- **Data-acquisition decision rule.** Directional (survivorship/selection) bias favors passes. Reject branch: no clean-data spend — a reject under biased-favorable data is robust. Pass branch: escalate to survivorship-free PIT data (Norgate-class), attempt self-rejection on confirmation. Cost-optimal confirmatory design.
- **Directional-bias principle.** Universe/selection bias is favorable → rejects conservative (strong), passes optimistic (weak). "Failed under biased data" is stronger, not weaker.
- **β three-layer decomposition.** β selection = benchmark (Passive ETF-12 v1); β implementation = cost model (symmetric); β timing = only permitted candidate edge. Alpha decomposition filters β-resonance before any edge claim.
- **Machine-of-record rule.** `research/experiments/*.json` (spec) is the executed truth; docs are interpretation. Spec wins on conflict; erratum, not silent edit (cf. research-protocol universe erratum).
- **Institutional KPI mix.** Contribution (net, cost/risk-adjusted, long-horizon) + process discipline (reproducibility, no mining) + throughput (ideas evaluated, hit rate). Pure factor-combination grinding is screened as overfitting.
- **Idea supply channels.** Literature/factor-zoo mining, new data arrival, portfolio-feedback loop, mechanism-first. Not inspiration.
- **Orthogonal axes.** Frequency × data type × strategy class. Alt data ≠ event trading. Most institutional AUM: daily-frequency systematic on standard OHLCV + fundamentals; HFT is a corner.
- **Individual's only non-arbitrageable edge.** Not self-deceiving; negative knowledge compounds; diagnostic-lab > treatment-clinic framing.
- **Candidate sourcing: product catalog.** Institutional product families (trend/CTA, cross-sectional momentum, value/quality, carry, stat-arb, risk parity, vol-risk-premium, PEAD, multi-strategy) as a 9A candidate source; filter = "which one can our long-only, daily, standard-data machine legitimately test."
- **"Beat SPY" is not the acceptance bar.** Machine bar = statistically valid vs the preregistered null (net of costs, not dominated by the benchmark), then `continue research` — even without SPY/buy-and-hold out-performance. Most institutional defensive/risk-premium products underperformed the 2006+ equity super-bull; their purpose is low-correlation value and drawdown control, not beating beta. Caveat: p-vs-null is necessary, not sufficient — the full gate (materiality, benchmark non-domination, cost stress, robustness) still applies.
