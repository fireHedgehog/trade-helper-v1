- **Higher-highs/higher-lows (Dow theory swing structure)** — untested
  here. Distinct from SMA cross (moving averages): raw local swing-point
  sequencing defines the trend, not an average.
- **Fibonacci retracement levels** — does price react at 38.2%/61.8%
  more than chance? Never tested.
- **Golden cross / death cross (50/200 SMA)** — the media-hyped
  parametrization, different windows from the closed 20/50 SMA Cross v1
  result — not a repair of it, a different claim.
