# ADR 0006: Macro data contract

Status: accepted (contract); implementation pending.

## Context

Macroeconomic series and market OHLCV are distinct data species. A macro observation for reference period $R_i$ becomes public at a release datetime $\tau_i$, then undergoes revisions indexed by $k \in \{0,1,\dots\}$. Market bars are observable at their session close. Conflating the two alignment conventions introduces look-ahead bias: a value that is final today was neither final nor published at a past decision date.

The current ingestion path (`fred.py`) retrieves `fredgraph.csv`, the **final-revised** FRED series. [ADR 0002](0002-market-data-contract.md) correctly asserts that FRED series are non-tradable context, excluded from strategy bars and execution assumptions, but it does not define a point-in-time, revision, or alignment discipline. This ADR supplies that discipline and states the condition under which macro data may ever acquire signal status.

## Nomenclature (binding definitions)

| Term | Symbol | Definition |
|---|---|---|
| Reference period | $R_i$ | Calendar period to which observation $i$ pertains. |
| Release datetime | $\tau_i$ | Instant at which the initial value $x_i^{(0)}$ for $R_i$ is first made public. |
| Revision index | $k$ | Publication ordinal for observation $i$: $k=0$ initial release; $k>0$ revised value. |
| Publication time | $\tau_i + \Delta_i^{(k)}$ | Time at which the $k$-th value of observation $i$ becomes public; $\Delta_i^{(k)}$ is the revision lag. |
| Vintage | $\mathcal{V}_t$ | Cross-section of values published at or before time $t$: $\mathcal{V}_t = \{x_i^{(k)} : \tau_i + \Delta_i^{(k)} \le t\}$. |
| Information set | $\mathcal{I}_t$ | $\sigma$-algebra generated by the vintage: $\mathcal{I}_t = \sigma(\mathcal{V}_t)$. |
| As-of (availability) constraint | — | Any decision at time $t$ may depend only on $\mathcal{I}_t$. |
| Consensus forecast | $f_i$ | $f_i = \mathbb{E}[x_i^{(0)} \mid \mathcal{F}_{\tau_i^-}]$: expectation of the initial release conditioned on the pre-release public information set $\mathcal{F}_{\tau_i^-}$. |
| Surprise | $s_i$ | $s_i = x_i^{(0)} - f_i$: initial-release value minus consensus forecast. |

## Decision

1. **Scope.** FRED/macro series are non-tradable, descriptive context. They are excluded from Yahoo refresh, strategy bars, and execution assumptions (per ADR 0002), and they never generate entry candidates. This is the default state, not a temporary convenience.

2. **Point-in-time gate.** No macro-based inference, backtest, statistic, or signal is permitted unless every observation used at decision time $t$ is a member of $\mathcal{V}_t$. The canonical point-in-time source is FRED ALFRED (Archival FRED) vintage snapshots. Final-revised `fredgraph.csv` may be used for descriptive display only, never for inference.

3. **Timestamp discipline.** Every stored observation carries the tuple $(R_i, \tau_i, k)$. Research alignment is by release datetime $\tau_i$, never by reference period $R_i$. A value with $\tau_i + \Delta_i^{(k)} > t$ is not in $\mathcal{I}_t$ and is unusable at $t$.

4. **Revision policy.** Store the initial and every subsequent revision; never silently overwrite. A revision that alters a stored value changes the series data fingerprint and must be recorded as provenance, extending ADR 0002's fingerprint requirement to macro series.

5. **Estimand declaration (surprise vs level).** A macro "edge" is a claim about $\mathbb{E}[R_{t+1} \mid \mathcal{I}_t]$, the conditional expectation of a forward return given the vintage. Because efficient pricing conditions on expectations, a level-based claim (predictability from $x_i^{(k)}$ alone) is the stronger, less plausible claim; a surprise-based claim requires a consensus-forecast history $\{f_i\}$. Every macro protocol must declare which estimand it tests and either supply the corresponding data or state that the estimand is unmeasurable with available data. An unmeasurable estimand is not a research result.

6. **Small-sample discipline.** Macro observations are not independent: they are regime-dependent. The effective sample is the number of independent regime episodes $N_{\text{ep}}$, not the number of monthly observations $n$. Required:

   - report $N_{\text{ep}}$ for the conditioning regime;
   - require $N_{\text{ep}} \ge$ the preregistered minimum for the relevant regime;
   - use dependence-consistent standard errors (e.g. Newey–West HAC, stationary or block bootstrap);
   - set acceptance thresholds above those used for daily-frequency strategies, reflecting $n_{\text{eff}} \le n$.

7. **Non-stationarity.** Macro relationships are regime-dependent. Any macro inference must include sub-sample stability by regime and a structural-break check (e.g. Chow test; Bai–Perron multiple-break estimation). No stability claim is admissible without breakpoint-aware evidence.

8. **Release calendar.** Maintain a machine-readable release calendar of scheduled $\tau_i$ per series (BLS, BEA, FRED). A human-facing calendar is not an as-of source. Macro freshness is the comparison of the last observed release against the next scheduled release; it is not a market-session comparison.

9. **Upgrade path.** Macro becomes a candidate source only when all of the following hold:

   (a) ALFRED vintage and release metadata are ingested and schema-validated;
   (b) the clause 5 estimand is declared with the required data present;
   (c) the hypothesis passes Stage 9A scoring under [model-acceptance-standard](../model-acceptance-standard.md);
   (d) the protocol is preregistered with an episode-aware design satisfying clauses 6–7.

## Statistical definitions

**Look-ahead bias condition.** A statistic $\hat\theta$ is contaminated iff $\exists\, x_i^{(k)}$ used in computing $\hat\theta$ such that $\tau_i + \Delta_i^{(k)} > t$ while a decision is made at $t$.

**Trial-count deflation.** The total number of macro trials $N_{\text{trials}}$ inflates the best observed statistic. Apply selection-bias correction (Bailey & López de Prado, 2014): under $N_{\text{trials}}$ independent draws, the expected maximum Sharpe ratio is approximately

$$E[\max \widehat{SR}] \approx \sqrt{2 \ln N_{\text{trials}}},$$

and the Deflated Sharpe Ratio is

$$\mathrm{DSR} = \Phi\!\left(\frac{(\widehat{SR} - SR_0)\sqrt{n-1}}{\sqrt{1 - \gamma_3\,\widehat{SR} + \frac{\gamma_4 - 1}{4}\,\widehat{SR}^2}}\right),$$

where $SR_0 = E[\max \widehat{SR}]$, and $\gamma_3$, $\gamma_4$ are the skewness and excess kurtosis of the return series. The formula assumes independent trials; correlated candidates mis-deflate it, so pair it with dependence-valid stepwise control (Romano & Wolf, 2005).

**Dependence-consistent variance.** Newey–West (1987) HAC estimator with Bartlett kernel:

$$\hat\sigma^2_{\mathrm{HAC}} = \hat\gamma_0 + 2\sum_{j=1}^{L} \left(1 - \frac{j}{L+1}\right) \hat\gamma_j,$$

where $\hat\gamma_j$ is the $j$-th sample autocovariance and $L$ is the lag length chosen by bandwidth rule.

**Estimation refinements.** The raw estimators remain valid; institutional practice applies data-driven calibration rather than replacement. HAC: automatic bandwidth (Newey & West, 1994) or quadratic-spectral kernel (Andrews, 1991), prewhitening (Andrews & Monahan, 1992), fixed-b critical values in finite samples (Kiefer & Vogelsang, 2005). Bootstrap: data-driven block length (Politis & White, 2004). Breaks: unknown-breakpoint tests (Andrews, 1993; Bai & Perron, 2003).

## Consequences

- Currently stored final-revised series (e.g. `DGS2`, `DGS10`, `CPIAUCSL`, `PAYEMS`) are display-only; they carry no research-evidential status.
- Any future macro hypothesis must cite the clauses of this contract.
- Satisfying clauses 2–4 requires a new ingestion path (ALFRED), a schema extension (release/revision columns), and a fingerprint extension.
